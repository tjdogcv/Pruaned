# Ponytail Skill

Before writing or refactoring code, run through the Ponytail ladder:
1. Does this need to exist? -> skip if unnecessary (YAGNI).
2. Already in this codebase? -> reuse it, don't rewrite.
3. Native platform feature exists? -> use standard HTML5/CSS/JavaScript features.
4. Keep code terse, clear, declarative, and 100% safe.
5. High readability and zero bloat.
